## 5. Ponytail Audit Decisions & Governance

| Audit Item | Ponytail Suggestion | Decision | Architectural Rationale |
|---|---|---|---|
| **Structural File Validator** | Replace JSZip/pdf-lib with magic bytes + size check | ❌ **REJECT** | D7.4 established structural validation for DOCX/PPTX/XLSX/PDF as part of the artifact trust chain. Magic bytes prove only container type, not XML/AST schema validity. |
| **Live Probes D7.1–D7.4** | Delete probe scripts as "superseded" | ❌ **REJECT** | Critical reproducibility tools for live interface, AgentLoop, lifecycle, and native save/export verification. Preserved and supplemented with `live-probe-d7-5.mjs`. |
| **Shared IPC Types** | Import directly from `automation-types.ts` into renderer/preload | ❌ **REJECT** | Must not violate Electron sandbox isolation. Renderer/preload code must never import Node-only dependencies. |
| **Generation Contract Fields** | Remove `theme`, `audience`, `tone`, `detail_level`, `sections_outline` as "speculative" | ❌ **REJECT** | Part of the authoritative generation contract passed between Limo and GenOffice. Premature removal creates breaking compatibility risks with future phases. |
| **Preflight Health Check** | Remove redundant `health_check()` before `open_file()` | ✅ **ACCEPT** | `open_file()` already attempts local HTTP action directly with error handling and OS shell fallback; preflight check was superfluous. |
| **Unused Workspace Artifact State** | Remove dead `activeWorkspaceArtifact` state in `frontend/src/App.tsx` | ✅ **ACCEPT** | Dead state leftover from earlier preview panel design. Safely removed. |
| **Route Aliases in Automation Server** | Remove alias routes (`/api/v1/generate`, `/api/v1/jobs`) | ❌ **REJECT** | Tests and external clients (`engine_router.py`, `genoffice_client.py`) rely on standard REST naming. |
