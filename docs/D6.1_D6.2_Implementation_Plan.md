# Limo Phase D6 Implementation Plan: D6.1 & D6.2 (Revised)

> **Scope**: D6.1 (Transformation Request & Configuration) and D6.2 (Output Planning & Engine Routing) ONLY  
> **Pre-requisites**: D3 (Persistence & Diagnostics), D4 (Agent Infrastructure), and D5 (Content Ingestion & Understanding) are locked foundations  
> **Core Principles**:
> - D4 Agent handles natural language understanding; D6 is 100% deterministic planning and routing.
> - D6 consumes D5 CanonicalContent; it never re-reads or re-extracts raw source files.
> - Native engine reuse (GenOffice for Docs/Slides/Sheets; OpenMontage/MPT for Video).
> - Explicit domain failure contracts inheriting from `LimoException` — zero fake generation or synthetic pipelines.

---

## 2. Responsibilities: D6.1 vs. D6.2

### D6.1 — Transformation Request & Configuration
* **Single Responsibility**: Deterministic validation, boundary enforcement, and parameter reconciliation for transformation requests.
* **Division of Labor**:
  - **D4 Agent Loop**: Performs all natural language comprehension (e.g., parsing "make it 15 slides for executives in dark mode" into `{"slide_count": 15, "audience": "Executive", "theme": "dark"}`).
  - **D6.1 Component (`TransformationConfigResolver`)**: Receives pre-extracted structured arguments, validates them against domain schemas, and reconciles them with `CanonicalContent.intent`.
* **Key Tasks**:
  1. Validate that the target `CanonicalContent` exists in SQLite and record its immutable `canonical_id` and `canonical_hash`.
  2. Map incoming structured format requests or active `FeatureMode` into canonical `OutputFormat` enums.
  3. Reconcile editorial posture (`audience`, `tone`, `language`, `detail_level`, `objective`, `style`) by merging canonical defaults with structured user overrides.
  4. Enforce strict parameter validation rules (e.g., slide counts 1..100, video duration 15..900s, valid ISO language codes).
  5. Produce the frozen `TransformationRequest`.

### D6.2 — Output Planning & Engine Routing
* **Single Responsibility**: Determine the discrete deliverables required, build the execution manifest, and assign authoritative engine routes.
* **Division of Labor**:
  - D6.2 does not execute generation; it defines the execution contract.
  - Assigns explicit `EngineRoute` metadata, declaring target extensions, target roadmap phases, and engine availability (`is_implemented`).
* **Key Tasks**:
  1. Decompose multi-deliverable requests (e.g. user requested a Presentation, an Executive Summary, and a Spreadsheet) into discrete `PlannedDeliverable` items.
  2. Route each deliverable to its primary engine via the Authoritative Product Routing Table.
  3. Reject unknown format requests immediately with `UnsupportedFormatError`.
  4. Explicitly mark all future engines (`D6.3`, `D7`, `D8`) as `is_implemented=False`.
  5. Guard dispatch attempts: if execution is attempted on an unimplemented engine, fail explicitly with `UnimplementedEngineError` (derived from `LimoException`).
  6. Persist the plan as a `TransformationJob` contract in SQLite.

### 3.2 UI `FeatureMode` to `OutputFormat` Mapping
* **`FeatureMode.DOCS`**: Maps to `OutputFormat.DOCUMENT`. If the user or agent specifies an advisory or summary, specialized formats `OutputFormat.ADVISORY` or `OutputFormat.SUMMARY` are used.
* **`FeatureMode.SLIDES`**: Maps to `OutputFormat.PRESENTATION`.
* **`FeatureMode.SHEETS`**: Maps to `OutputFormat.SPREADSHEET`.
* **`FeatureMode.VIDEO`**: Maps to `OutputFormat.VIDEO`.
* **`FeatureMode.NONE` / Default**: Evaluates explicit requested formats or falls back to `OutputFormat.DOCUMENT`.

### 5.2 Transformation Request Contract (D6.1)
```python
from datetime import datetime, timezone
from typing import Any, Dict, List, Optional
from pydantic import Field, field_validator
from .base import LimoBaseModel
from .enums import OutputFormat
from .generation_config import GenerationConfig
from ..core.ids import generate_uuid

def generate_request_id() -> str:
    return f"req_{generate_uuid()}"

class TransformationRequest(LimoBaseModel):
    """Validated input specification for deliverable transformation (Phase D6.1)."""
    id: str = Field(default_factory=generate_request_id, description="Request ID with 'req_' prefix")
    project_id: Optional[str] = Field(default=None, description="Associated project ID")
    session_id: Optional[str] = Field(default=None, description="Active chat session ID")
    canonical_id: str = Field(description="ID of the underlying D5 CanonicalContent")
    canonical_hash: str = Field(min_length=64, max_length=64, description="Cryptographic SHA-256 hash of CanonicalContent")
    requested_formats: List[OutputFormat] = Field(min_length=1, description="Target transformation deliverables")
    config: GenerationConfig = Field(default_factory=GenerationConfig, description="Reconciled generation configuration")
    user_prompt: Optional[str] = Field(default=None, description="Raw user prompt or direct guidance")
    created_at: datetime = Field(default_factory=lambda: datetime.now(timezone.utc))

    @field_validator("id")
    @classmethod
    def validate_request_id(cls, v: str) -> str:
        if not v.startswith("req_"):
            raise ValueError("TransformationRequest ID must start with 'req_'")
        return v
```

## 6. Deterministic Configuration Reconciliation (D6.1)

D6.1 contains **zero language-understanding logic**. It performs pure, deterministic dictionary/schema reconciliation:

```text
Structured Overrides from D4 Agent Tool Call
(e.g., {"audience": "Board", "presentation": {"slide_count": 12}})
                     │
                     ├────────► Highest Precedence
                     │
Canonical Intent Baseline from D5 CanonicalContent
(e.g., primary_purpose="Alert CISO to exploit", target_audiences=["Security Team"])
                     │
                     ▼
Deterministic Reconciliation Logic (TransformationConfigResolver)
  - If field in overrides and not default -> use override
  - Else if field in canonical.intent -> inherit from canonical
  - Else -> use system default (GenerationConfig standard)
```

### Concrete Reconciliation Code:
```python
class TransformationConfigResolver:
    """Pure deterministic reconciler combining structured overrides with CanonicalContent."""

    def resolve(
        self,
        canonical: CanonicalContent,
        structured_overrides: Optional[GenerationConfig] = None,
        requested_formats: Optional[List[OutputFormat]] = None,
        active_mode: Optional[FeatureMode] = None,
        user_prompt: Optional[str] = None,
        project_id: Optional[str] = None,
        session_id: Optional[str] = None,
    ) -> TransformationRequest:
        # 1. Resolve Target Formats
        formats = self._resolve_formats(requested_formats, active_mode, canonical)

        # 2. Reconcile Editorial Posture
        base_cfg = structured_overrides or GenerationConfig()
        
        # Audience: User override > Canonical intent > Default ("Executive")
        audience = base_cfg.audience
        if audience == "Executive" and canonical.intent.target_audiences:
            audience = canonical.intent.target_audiences[0]

        # Objective: User override > Canonical purpose mapping > Default (INFORM)
        objective = base_cfg.objective
        if objective == CommunicationObjective.INFORM and canonical.intent.primary_purpose:
            objective = self._map_purpose_to_objective(canonical.intent.primary_purpose)

        reconciled_config = base_cfg.model_copy(
            update={
                "audience": audience,
                "objective": objective,
            }
        )

        return TransformationRequest(
            project_id=project_id,
            session_id=session_id,
            canonical_id=canonical.id,
            canonical_hash=canonical.content_hash,
            requested_formats=formats,
            config=reconciled_config,
            user_prompt=user_prompt,
        )

    def _resolve_formats(
        self,
        requested_formats: Optional[List[OutputFormat]],
        active_mode: Optional[FeatureMode],
        canonical: CanonicalContent,
    ) -> List[OutputFormat]:
        if requested_formats:
            return list(dict.fromkeys(requested_formats))

        if active_mode:
            mode_map = {
                FeatureMode.SLIDES: [OutputFormat.PRESENTATION],
                FeatureMode.SHEETS: [OutputFormat.SPREADSHEET],
                FeatureMode.DOCS: [OutputFormat.DOCUMENT],
                FeatureMode.VIDEO: [OutputFormat.VIDEO],
            }
            if active_mode in mode_map:
                return mode_map[active_mode]

        return [OutputFormat.DOCUMENT]
```

## 7. Domain Exception Hierarchy for Explicit Failures

All D6 errors inherit cleanly from `LimoException` in `backend/app/exceptions.py`, ensuring consistent handling by the global HTTP exception handlers and logging pipelines:

```python
from fastapi import status
from ..exceptions import BadRequestError, LimoException

class UnsupportedFormatError(BadRequestError):
    """Raised when an output format is not in the recognized OutputFormat registry."""

    def __init__(self, raw_format: str, supported_formats: List[str]):
        super().__init__(
            message=f"Unsupported deliverable format '{raw_format}'. Supported formats: {supported_formats}",
            details={"requested_format": raw_format, "supported_formats": supported_formats},
        )


class UnimplementedEngineError(LimoException):
    """Raised when an execution dispatch is attempted on an unbuilt engine (D6.3+, D7, D8)."""

    def __init__(self, engine_type: str, target_phase: str):
        super().__init__(
            message=(
                f"Execution engine '{engine_type}' is scheduled for Phase {target_phase} "
                f"and is not yet available in Phase D6. Zero fake artifacts will be generated."
            ),
            error_code="UNIMPLEMENTED_ENGINE",
            status_code=status.HTTP_501_NOT_IMPLEMENTED,
            details={"engine_type": engine_type, "target_phase": target_phase},
        )
```

## 8. Integration with Limo Agent & LangGraph

D6 does **not** create a new agent loop or state machine. It is a deterministic business layer:

```text
                  Agent Chat / HTTP API
                            │
                            ▼
              TransformContractTool (D4 Tool)
                            │
                            ▼
               TransformService (Existing)
                 ├── Step 1: D6.1 TransformationConfigResolver
                 ├── Step 2: D6.2 OutputPlanner & EngineRouter
                 ├── Step 3: Persist OutputPlan into SQLite Job
                 └── Step 4: Notify LangGraphBridge
```

### 8.1 Tool Update (`backend/app/agent/tools/transform_tool.py`)
`TransformContractArgs` will accept structured `configuration: Optional[Dict[str, Any]] = None`. When called:
1. It parses format strings into `OutputFormat` (including new formats: `spreadsheet`, `document`, `markdown`, `html`, `pdf`).
2. It delegates to `TransformService.create_transform_contract()`.

### 8.2 Orchestration Bridge (`backend/app/agent/orchestration/bridge.py`)
`LangGraphBridge` defines `WorkflowStage.GENERATE`.
- D6 registers its planner as the pre-generation planner:
  ```python
  bridge.register_stage_handler(WorkflowStage.GENERATE, output_planner.plan_generation_stage)
  ```
- When `GENERATE` stage is dispatched:
  1. It consumes the `TransformationRequest`.
  2. It generates the `OutputPlan`.
  3. It validates engine readiness (`is_implemented`).
  4. If an engine is unbuilt (D7 GenOffice, D8 Video, D6.3 Social), it raises `UnimplementedEngineError` and transitions `WorkflowState.status = WorkflowStatus.FAILED` with a detailed error report. Zero fake generation occurs.
